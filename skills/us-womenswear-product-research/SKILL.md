# 美国女装选品验证

在选品语境或用户单独发来可辨认的女装款式且没有指定其他操作时，直接进入 [美国市场全渠道调研](references/item-analysis.md)。一张款图、一条商品或款式视频链接、一个 ASIN 或一段可搜索的款式描述就能开始。「看看这款」「这款呢」按同样方式处理。关键结构不明且会改变结论时，先集中确认，独立取证可同时进行。用户只要求修图、快评、只看评论或只查某平台时，按指定操作和范围执行。

## 按问题取证

| 要核对的问题 | 参考 |
|---|---|
| 品牌官网热销新品、上新扩色、分色分码库存与原款反查 | [美国市场全渠道调研](references/item-analysis.md) 与 [品牌新品取证口径](references/report-format.md#正文) |
| TikTok 原款、成交、传播与跟款时机 | [TikTok Shop 候选款](references/tiktok.md) |
| 参考款面料、版型、尺码、颜色、购买理由与售后风险 | [买家与视频评论](references/reviews.md) |
| 亚马逊价带、同版竞品、父体销量、季节与入场 | [亚马逊美国站选品](references/amazon-us.md) |
| 指定选品策略或找新链接、关键词与变体机会 | [17 项战术选品](references/amazon-tactics.md) |
| 四季需求与下一季穿法 | [四季款判断](references/year-round.md) |

把关键指标连到原商品或数据源，注明日期、站点、统计范围、规格和是否估算。分别标注原款、同版不同色、近款和局部设计对标。先读公开来源及已有导出，FastMoss 或卖家精灵等付费额度用于定向补决定性缺口。取不到时继续其他可核验部分。

默认按 [单款调研报告交付标准](references/report-format.md) 出完整报告。先给允许动作和入围状态，再交付款式结构、双平台证据、买家需求、四季判断、产品／运营／达人／内容四维评审、首版样衣和证据附录。多款使用统一的对标与优先级。研究所用方法见 [来源](references/sources.md)。
