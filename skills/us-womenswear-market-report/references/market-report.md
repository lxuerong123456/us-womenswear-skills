# 美国女装市场日报

计划任务每隔两天扫一次美国市场。也可应用户要求即时跑一期。报告标题使用报告生成日，并分别列数据最新日期、时区和窗口。默认观察美国 TikTok Shop 与 Amazon US，覆盖上衣、连衣裙、裤装、套装与相关外穿针织。

## 默认选题优先级

- **主线是下一季值得提前打样的款，四季款优先。** 明确报告的目标季节和年份，按用户开发周期或本次任务确定。先找适合下一季上架、且淡季也有需求的款，其次是有证据支持跨季穿着和购买的观察款，再看季节性明确且仍赶得上打样与上架的款。用 [四季款判断](year-round.md) 标注证据等级。
- **另外留一个 TikTok 新趋势位置。** 这个位置容纳当季或正在出现的款。优先选能核对原款、出现明确求购以及近期成交或独立达人扩散，并且有具体开发切入点的款。标明这条线索的成熟度和还要补的证据。当期没有足够线索，就在专栏写暂无合适候选。

## 取数与比较

1. 读取本任务上一期有可核实数据的报告及观察名单。第一期建立基线。可同比时用相同站点、细分类目、指标、商品标识和等长窗口。没有可比上期时，写本期快照。
2. **TikTok Shop** 用 [TikTok 候选款筛选](tiktok.md)。用已核对的女装类目 ID 和 `product_rank_top_selling` 查最近完整日或周。用 `product_rank_new_listed` 查新品起量，上市区间用工具允许的较早完整日期，最新日期通常为数据端四天前。按首三天销量发现新品时注明首三日口径。选最值得跟进的商品用 `product_overview` 或 `product_sales_trend` 复核，必要时找原视频。若最近两天和前两天四个完整有效日都有逐日数据，可按两天对两天比较；否则用有明确边界的最新可比 7/14/28 日窗口。重叠滚动快照的差值、榜单掉出前列、缺货与推广变化分别解释。
3. **Amazon US** 用 [17 项战术选品](amazon-tactics.md) 中与当期目标相关的几项。用最新有数据的完整周或月查关键词，周 ABA 可用 `aba_research_weekly`，月可用 `aba_research_monthly` 和 `keyword_miner`；商品和类目用最新可用的已结束自然月。遇到最新月还未归档，标实际已取月。跨期报告遇到相同月度快照就说明数据周期相同，复用已验证数据；有新快照、新候选或证据缺口再定向刷新。正式清单按 [亚马逊美国站选品](amazon-us.md) 复核父体、季节和入场。
4. 重点抽查足以改变结论的真实商品、评论与变体。不同数据源的市场线索可放在同一款，但逐项保留数据口径。工具未连接、无额度、无权限、数据滞后或空返回时，继续完成可取的一侧。公开商品页、原视频和已核实旧快照分别标注窗口与局限。只有新证据才能写成新变化。没有可验证变化时允许报告「本期暂无确认的新信号」。

## 日报结构

- **本期变化**。用不超过三句话交代有什么变化、最值得看什么和最大数据缺口。
- **下一季优先打样候选**。先列有四季需求证据的款。每款列「目标季节／四季判断／为什么值得做／最先打样或验证什么」，附商品、原视频或父 ASIN、数据窗口、价带和退货风险。需要给春夏正式入围结论时单列父体规模与独立卖家入场。只显示当期有判断价值的变化或代表性数据，销量估算清楚标注。
- **TikTok 新趋势（1 个位置）**。给原视频或商品链接、款式结构、近期销量或排名、明确求购或达人变化，以及能执行的下一步。
- **下步行动**。按「可打验证样／继续跟踪／暂缓」写具体动作。优先报最值得跟进的几款，附可打开的链接。如果来源覆盖有限，说明实际扫描的类目和样本，直接列需补的证据。

任务指定归档目录时，每期写一份带日期的 Markdown 报告，保留上一期文件，在当前对话返回摘要和报告链接。写清 TikTok 商品 ID、Amazon 父 ASIN、关键词和覆盖窗口，方便下期去重与比较。报告日期用于归档，来源日期用于比较。
