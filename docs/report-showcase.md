# 调研报告交付展示

[返回项目首页](../README.md) · [完整单款示例](../examples/product-research.md) · [市场日报示例](../examples/market-report.md)

这里把四类此前做过的女装调研归纳成一份脱敏的交付概览。两份公开示例展示写法，所用数字均为模拟数据。

## 四个实际调研方向

| 调研项目 | 研究怎么展开 | 此前交付的内容 |
|---|---|---|
| **查找 Free People 热销新品** | 先扫官网新品、扩色和分色分码库存，再反查 TikTok 多位独立达人是否在展示同款。品牌原款、平替对比视频与局部近款分别计。 | 新品机会清单、同款视频和达人比对、商品与穿着场景判断。评论者自填年龄按已填写样本和总评价数分别报告。 |
| **分析 TikTok 女装视频选品** | 核对画面、挂车与目标商品，同款跨达人去重，分清纯内容热度、明确求购和可核实成交。复查旺季、投放和近期是否还有入场窗口。 | 候选、观察和淘汰表，视频与商品并列表，互动、成交与归因对照，差异化方案、样衣验收和按需的达人内容建议。 |
| **完善参考产品评论分析** | 分开查实际买家、视频观众和创作者回复，按面料、版型、尺码、颜色、场景及使用后果编码。核对样本、规格和时间窗。 | Word/PDF 跟款报告、独立评论证据表、主题计数、变体和颜色线索，及从客诉到打样动作的对应关系。 |
| **规划明年春夏亚马逊女装选品** | 从具体结构出发找同版和可比款，放在一起比图、比价格和旺季。核验单一父体逐月销量，另查新卖家持续卖动与售后风险。 | 带款图对照的市场调研报告、父体逐月销量 Excel、春夏入围与观察清单、从起量月倒推开发时间的建议。 |

## 一份完整报告长什么样

| 阅读顺序 | 读者能带走什么 |
|---|---|
| **先看决策** | 三句话了解为什么推进、主要疑点以及下一步。打样、季节入围和小批测试各有理由。 |
| **再看款式和市场** | 原款与可比竞品关系、面料和版型、颜色尺码、价格与库存；TikTok 的视频与成交、Amazon US 的关键词和父体月销、官网及零售对标。 |
| **再看客户和四季** | 哪些人因为哪些穿法和卖点考虑买；哪些问题会影响穿着或退款；暖季和冷季穿法能否成立，淡季成交验证到哪一步。 |
| **最后看开发动作** | 产品、运营、达人和内容四维开品评审。每条改款写原问题、解决方式、新风险和通过标准。需要时给开品主表可直接填的条目。 |
| **附录复核** | 原始来源和统计窗口、评论分母和主题、父体逐月与日均、数据冲突和待查事项。支持导出时可按任务增加表格或文档。 |

## 两种报告的重点

- **单款报告**从图片、视频、商品链接或 ASIN 开始，以款式开发决定和试穿方案收尾。可以用[高腰弹力直筒裤示例](../examples/product-research.md)看证据如何影响裤长、腰头、四季定位和春夏入围。
- **市场日报**从市场机会开始，先排下一季可打样的四季款，再给一个值得追的 TikTok 新趋势，并记录当期覆盖、变化和下期要查的字段。 [查看日报](../examples/market-report.md)

完整字段和导出方式见 [单款调研报告交付标准](../skills/us-womenswear-product-research/references/report-format.md)。
